# assets/ — empty in v0.1

This folder is intentionally empty for **Mobile App Builder** (`mobile-app-builder`).

## What belongs here later
- Output templates (report shells, checklists, decks outlines)
- Sample inputs for demos
- Icons, fonts, or brand tokens used only in produced artifacts

## Tips for Mobile App Builder
- Put instructions in `SKILL.md` or `references/`, not here
- Keep binaries small; link large media externally if needed
- Name files clearly (e.g. `report-template.md`, `checklist.md`)
